## 2026-11-25 友誼賽：直播網址

前置：`docs/tournament/live-url-2026-11-25.sql` 已在 v2 Supabase 執行過一次（加 `live_url` 欄位、payload 多送 `liveUrl`），
前端 v19（含 `js/live.js`）已上線。**v19 至少要在賽前一天上線**：Service Worker 會先給舊頁面、背景才換新版，
上線前開過觀賽頁的手機，上線後第一次打開還是沒有直播框的舊頁面。

- 拿到 YouTube 直播網址後，在 SQL editor 跑（`watch?v=`、`youtu.be/`、`/live/`、`/embed/` 網址或 11 碼影片 ID 都可以）：
  ```sql
  update tournaments set live_url = '<直播網址>'
  where name = '貿聯×翰林2026羽球聯合友誼賽' and held_on = '2026-11-25'
  returning name, held_on, live_url;
  ```
  確認回傳**剛好 1 列**。觀賽頁開著的人約 10 秒內就會出現直播框，不用重新整理；輸分頁不會出現。
- **跑完一定要打開觀賽頁（`?t=`）看直播框有沒有出現**：其他格式（YouTube Studio 網址、頻道的 `/@名稱/live`、shorts）
  會被當成沒填、安靜地不顯示，只有這一步看得出來填錯。直播框出現但播不了，先確認直播的瀏覽權限是「公開」或「不公開」
  （「私人」嵌不進網頁）、頻道沒有關閉嵌入；框下方的「在 YouTube 開啟」仍可用。
- 有人說沒看到直播框：請他重新整理一次頁面（手機上的舊版快取，見上方前置）。
- 要拿掉直播框：
  ```sql
  update tournaments set live_url = null
  where name = '貿聯×翰林2026羽球聯合友誼賽' and held_on = '2026-11-25'
  returning name, live_url;
  ```
