## 2026-11-25 友誼賽：開播流程（2026-11-19 實測）

頻道「翰羽羽球社」（0 訂閱）用手機 PRISM＋串流金鑰推流可以開播；YouTube App 手機直播要 50 訂閱，不能用。
實測紀錄：`~/Downloads/badminton-friendly-1125/live-test-20261119.md`。

1. **YouTube 工作室 → 直播**（電腦）：打開直播控制中心，它會自動準備好「下一場」直播（每場影片 ID 都不同）。
   確認隱私設定是「不公開」（第一次建立時預設是「公開」）、兒童專屬選「否」。
2. **開啟「允許嵌入」（每一場都要）**：工作室 → 該場的「影片詳細資料」→「顯示進階設定」→ 授權 → 勾「允許嵌入」→ 儲存。
   預設是**不允許**，頻道設定裡也沒有預設值可改；沒勾的話，除了頻道擁有者本人，其他人在觀賽頁只會看到
   「影片擁有者已禁止在其他網站上播放這部影片」。用沒登入的身分檢查（回 `200` 才算好，`401` 是禁止嵌入）：
   ```bash
   curl -s -o /dev/null -w '%{http_code}\n' "https://www.youtube.com/oembed?url=https://www.youtube.com/watch?v=<影片ID>&format=json"
   ```
   （2026-11-19 已先把當時準備好的下一場 `eQLT-AcT-Hc` 開好嵌入；之後若又測試開播，它會被用掉，要對新的那場重做。）
3. **手機 PRISM**：自訂 RTMP，伺服器 `rtmp://a.rtmp.youtube.com/live2`＋串流金鑰（從工作室複製，不要用 LINE／Email 傳）；
   Widget → Web 貼疊加頁網址並**拉滿全畫面**；手機**橫拿**（或在 PRISM 設橫向）。
4. **PRISM 按開始直播**：工作室收到畫面後會**自動開播**，不用另外按「進行直播」；PRISM 顯示「請在 YouTube 網站點選開始按鈕」可以不管。
5. **把直播網址填進觀賽頁**：照下一節的 SQL 填 `https://youtu.be/<影片ID>`，觀賽頁約 10 秒內出現直播框。
   用**沒登入 YouTube 的裝置**（或別人的手機）開觀賽頁，按播放確認看得到。
6. **比賽中不要按「結束直播」**，打完最後一場才結束。結束後那一場就不能再接著播；
   萬一提早結束：先打開工作室直播頁讓它準備新的一場 → 重做第 2 步（允許嵌入）→ PRISM 停止、等 10 秒、重新開始 →
   用新的影片 ID 重跑下一節的 SQL。
