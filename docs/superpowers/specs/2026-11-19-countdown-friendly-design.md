# 排場主頁倒數橫幅改成友誼賽、不放觀賽連結（2026-11-19）

## 意圖
排場系統主頁（`index.html`）的倒數橫幅是 8/20 第三屆做的，現已結束隱藏。使用者 11-19 問友誼賽要不要也加，16:37 拍板：**加，但不放連結（方案 A）**。
看得到的人是上課時開排場頁的翰林羽球社社員；用途是炒氣氛、提醒日期。

## 為什麼不放連結
repo 是公開的。友誼賽觀賽頁會顯示貿聯同仁的名字（名單 SQL 因此只留在 Downloads、沒進 repo）；
觀賽連結寫進 `js/countdown.js` 等於任何翻 GitHub 的人都打得開那一頁。

## 目標
- 橫幅倒數到 2026-11-25 (三) 18:15，開打後顯示「比賽進行中」，21:00 後自動隱藏（比照第三屆留延誤緩衝；第 6 輪預定 19:30-19:45）。
- 點橫幅開的彈窗：倒數／進行中＋開打時間，再加一行「觀賽連結請看社團群組」；只有「關閉」按鈕，沒有「前往賽程」。
- 橫幅底下的提示字不再寫「查看賽程 ›」（沒有賽程可前往）：開打前「比賽資訊 ›」、進行中「觀賽連結請看社團群組」。

## 非目標
- 不改比賽頁（`tournament.html`）、不加任何後端。
- 不換插畫（`img/event-banner.jpg` 是通用羽球圖，沒有第三屆字樣）。
- 不改橫幅的視覺與 `<button>` 結構（2026-08-07 的「不可導航離開排場頁」照舊）。

## 反目標
- 友誼賽的觀賽通行碼出現在 repo 任何檔案裡。
- 第三屆那種「有連結」的用法壞掉（下次社內比賽要能再放連結）。

## 做法（Approaches）
1. **A. 只倒數、不放連結（採用）**：`EVENT` 不給 `url`，彈窗與提示字依「有沒有連結」切換。
2. B. 跟第三屆一樣放觀賽連結：方便，但名字從公開 repo 找得到，使用者不採用。

## 已決定的部分
- `EVENT.url` 變成選填：有 → 照舊（前往賽程／進入即時計分板）；沒有 → 上述「不放連結」行為。
- 判斷寫成純函式（彈窗內文、彈窗按鈕、橫幅提示字），渲染層只呼叫它們，才測得到。
- `EVENT`：名稱「貿聯×翰林2026羽球聯合友誼賽」、`startAt 2026-11-25T18:15:00+08:00`、`endAt 2026-11-25T21:00:00+08:00`、沒有 `url`。
- 換版 v21 → v22（`sw.js` 的 `PRECACHE_URLS` 已含 `js/countdown.js`，只換 `CACHE_NAME`；計分頁 `?v=` 由測試要求同步）。

## 前提（交給使用者）
- 「觀賽連結請看社團群組」要成立，觀賽連結（或 QR）要真的貼在羽球社群組。
