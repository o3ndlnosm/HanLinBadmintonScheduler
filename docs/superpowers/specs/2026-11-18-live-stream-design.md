# 觀賽頁嵌入 YouTube 直播（短設計）

2026-11-18。友誼賽（2026-11-25 18:15）當天會用 YouTube 直播。

## 為什麼

不在現場的同事打開觀賽頁，就能在同一頁同時看到直播畫面和即時比分，不用另外找直播連結。

## 使用者拍板

- 直播平台用 YouTube。不自建（評估過：觀眾流量、HTTPS、當天沒有備案，這些都會落在我們身上）。
- 直播網址存在賽事資料（Supabase `tournaments`），不寫在程式裡。拿到網址後跑一行 SQL，開著的頁面在下一次 10 秒更新時就會出現直播框。

## 行為

- **還沒填網址**：頁面跟現在一模一樣。
- **填了 YouTube 網址**：觀賽頁（`?t=`）在賽名下方、點數比分板上方出現 16:9 的直播框，不自動播放。
  框下方有一行「在 YouTube 開啟」連結。
- **輸分頁（`?c=`）不出現直播框**：記分的人在現場，不需要看直播；放了可能誤觸、外放聲音、多吃場館網路。
- **網址改了**（例如換一場直播）：下一次更新時換成新影片。**網址沒變**：直播框保持原狀，不重新載入、不中斷播放。
- **網址清空**：下一次更新時直播框消失。
- **比賽結束後**：網址還在就繼續顯示（可以看回放）。要拿掉就清空網址。
- **接受的網址格式**：`youtube.com/watch?v=…`、`youtu.be/…`、`youtube.com/live/…`、`youtube.com/embed/…`，
  含 `www.`、`m.` 開頭的子網域。也接受直接填 11 碼影片 ID。
  其他格式或其他網站一律當成沒填，不顯示，也不報錯。

## 反目標

- 直播框出錯不能讓比分、賽程、應援壞掉（包在 try/catch 裡，比照應援條的寫法）。
- 不能每 10 秒重新載入一次影片。
- 輸分網址的通行碼不能外流：直播框只對 YouTube 送出網域（`https://o3ndlnosm.github.io/`），
  整頁維持不送來源網址。
- 不能嵌入 YouTube 以外的網站：只從網址取出 11 碼影片 ID，自己組播放器網址
  `https://www.youtube.com/embed/<ID>`。

## 做法比較

| 做法 | 取捨 | 結果 |
|---|---|---|
| A. 網址存在 `tournaments.live_url`，經由讀賽事資料的共用函式送到前端 | 要改一次正式資料庫（加一欄、改一支函式），先在測試賽事驗過；當天只要跑一行 SQL，不用重新上版、不用重整 | **採用** |
| B. 網址寫在前端程式裡 | 要重新上版，手機重整兩次才換新版；repo 是公開的，不公開的直播連結會出現在 GitHub 上；也沒辦法不靠通行碼辨認是哪一場 | 不採用 |
| C. 自建串流伺服器 | 見「使用者拍板」 | 不採用 |

## 後端

- `alter table tournaments add column if not exists live_url text;`
- `tournament_public_payload` 的 `tournament` 物件多一個 `'liveUrl', t.live_url`。
  觀賽頁和輸分頁的讀取函式都經過它；前端只在觀賽頁顯示。
- SQL 檔放在 `docs/tournament/`，附上回復用的 SQL（把函式改回不含 `liveUrl` 的版本；欄位留著不影響任何東西）。
- 改之前先在 SQL Editor 讀出正式站目前的函式定義，跟 repo 裡的版本比對一致才改。

## 我做的決定（使用者可改）

1. 只在觀賽頁顯示，輸分頁不顯示。
2. 位置在賽名下方、點數比分板上方。
3. 不自動播放。
4. 框下方加一行「在 YouTube 開啟」：嵌入失敗時（頻道關閉了嵌入、瀏覽器擋掉）大家還是看得到。不要的話可以拿掉。
5. 比賽結束後網址還在就繼續顯示。

## 驗證

- 單元測試：網址取 ID（各種合法格式、其他網站、長得像 YouTube 的假網域、`javascript:`、空值）；
  直播框只掛一次、網址變了才換、清空就消失、只在觀賽頁出現、出錯不影響賽程。
- 上線後在正式站實測：拿一部公開的 YouTube 影片暫時填進某一場賽事（填哪一場先問），確認播得出來、
  沒有「錯誤 153」、手機寬度沒有水平捲動，最後清掉。
