# 比賽計分頁 F1 風格改版設計

日期：2026-08-03
狀態：已與使用者確認方向

## 背景

比賽計分頁（`tournament.html`）目前沿用排場系統 `css/style.css` 的藍色系。當初這樣做是為了不自創視覺，但比賽是獨立場合，使用者希望改成 **F1 賽事計時板** 的感覺。

明確排除：不沿用 v2 `badminton-scheduler` 既有的 Ferrari 風格 token，改以 F1 官網實測為依據。

## 依據（2026-08-03 實測 formula1.com）

以瀏覽器讀取 computed style 取得，非目測：

| 項目 | 實測值 |
|---|---|
| 頁面底色 | `#26262B`（暖調深灰，**非純黑**） |
| 表格區底色 | `#000000` |
| 分隔線 | `0.9px solid #303037`（設在儲存格，非列） |
| 品牌紅 | `#E10600`；另有 `#E8002D` |
| 次要文字 | `#AAAAAA` |
| 內文字體 | Titillium Web（Google Fonts 可免費取得） |
| 標題字體 | Formula1（專有，不可用；以 Titillium 粗體大寫逼近） |
| 數字字體 | Formula1Digits（專有；以 `font-variant-numeric: tabular-nums` 逼近） |
| 表頭 | 14px / 600 / uppercase / `#AAA` |
| 資料列 | 16px / 600 / `#FFF`，列高約 58px |
| 對齊 | 名次靠左，積分靠右 |
| 轉場 | `0.5s cubic-bezier(0.4, 0, 0.2, 1)` |
| 排名列 hover | **無**（刻意讓資料保持安靜） |

## 設計決策

### 色彩

- 頁面底 `#26262B`，卡片/表格區 `#000`，分隔線 `#303037`
- 主要文字 `#FFF`、次要 `#AAA`
- 頂部一條 `#E10600` 細線作為識別（比照 F1 導覽列的紅色底線語彙）
- **紅色只用於「需要使用者行動」**：可輸分的場次、送出按鈕。不當裝飾用

### 狀態顏色（保留語意，與品牌紅區隔）

| 狀態 | 顏色 | 理由 |
|---|---|---|
| 已確認 | 綠 | 正面完成 |
| 等待對方確認 | 琥珀 | 中性等待 |
| 比分不一致 | `#E8002D`（偏洋紅） | 與品牌紅 `#E10600` 區分，避免「紅＝可操作」與「紅＝出錯」混淆 |
| 未完成 | `#6A6A74` | 最低視覺權重 |

### 字體

- 載入 Titillium Web（400/600/700）＋ Noto Sans TC（中文）
- 標題大寫、加字距
- **所有比分與名次使用 `tabular-nums`**：數字更新時欄寬不跳動

### 隊伍代表色

五隊各配一個高辨識度顏色，在排名表與賽程列前顯示小圓點（比照 F1 車隊色）。
目的：五隊同時比賽時，隊長在手機上靠顏色快速定位自己那隊，比讀文字快。

### 動效

- 統一 `0.5s cubic-bezier(0.4, 0, 0.2, 1)`
- 比分確認時該列短暫亮綠再淡出
- 排名變動時列的位移平滑過渡
- **不做**跑馬燈、閃爍、持續動畫——現場隊長是要快速輸分，不是看表演
- 尊重 `prefers-reduced-motion`：關閉位移與閃爍，只保留顏色轉換

### 保留不變

- 版面結構（排名表在上、賽程在下、輪次分組）
- 所有互動行為與文案
- 隊長輸分彈窗的欄位配置

## 範圍

- 只改 `css/tournament.css`；`tournament.html` 僅在需要掛隊伍色圓點與字體連結時最小幅修改
- **不動** `index.html`、`js/script.js`、`css/style.css` 及排場系統任何檔案
- `js/tournament.js` 僅在渲染隊伍色圓點時最小幅修改

## 驗收

- 手機寬度（375/414px）下排名表與賽程不需橫向捲動
- 對比度全部達 WCAG AA（4.5:1）；特別檢查次要文字與狀態標籤
- 既有 167 項 jest 測試不受影響
- 真機或瀏覽器實測四種狀態（未完成／等待／不一致／已確認）與冠亞軍橫幅

## 不做

- 不做深淺色主題切換（比賽只在晚上室內，單一深色即可）
- 不引入 CSS 框架或建置流程
- 不改動資料模型或後端
