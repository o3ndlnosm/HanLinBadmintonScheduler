## 目標／非目標／反目標

- 目標：最後一輪開打前所有觀賽頁與直播畫面一起進入「冠軍時刻」；15 場打完一起「冠軍揭曉」；兩隊在所有畫面用代表色、一眼分得出來。
- 非目標：不改賽制、不改後端（RPC、資料表都不動）、不做主持人頁、不加音效。
- 反目標：
  - **輸分功能不能被影響**：輸分頁（`?c=`）不播冠軍時刻；冠軍時刻任何錯誤都不能讓賽程、輸分、應援壞掉（比照應援條包 try/catch）。
  - **觀賽頁不能被永久蓋住**：直播框、應援條、賽程在最終戰期間都要能用。
  - **直播畫面不能出現錯誤字**：比照疊加頁現有規則。
  - **第三屆與其他比賽不受影響**：配色與冠軍時刻都只在「兩隊剛好是貿聯、翰林」時啟用。

## 怎麼判斷進入哪個階段（純函式，`js/champion-moment.js`）

`finalPhase(view)` 回傳 `'none' | 'final' | 'done'`：

- 只在比點模式且兩隊剛好是 `貿聯`、`翰林`（名稱完全相同）時判斷，其他一律 `'none'`。
- `done`：`computeTeamPoints(...).allConfirmed` 為真，或 `tournament.status === 'finished'`。
- `final`：取比點場次中最大的 `roundNo` 為最後一輪；最後一輪**之前**的場次全部 `confirmed`，且還沒 `done`。
  最後一輪只有一輪（全部都是第 1 輪）時不進 `final`。
- 其他 `'none'`。

場次比分晚輸入時：`final` 會晚到；最壞的情況是最後一輪已經開打甚至打完才判斷到。
若第一次看到就已經是 `done`（中間沒看過 `final`），**跳過開場，直接播冠軍揭曉**。

`championInfo(view)`：`done` 時回傳勝方 `{ id, name, side: 'left'|'right', won, lost }`（沿用 `computeTeamPoints`）。

## 每台裝置只播一次

- 開場、揭曉各自記在 `localStorage`（鍵含比賽 id 與階段，例如 `cm:<tournamentId>:final`、`cm:<tournamentId>:done`）。
- 讀寫一律 try/catch；`localStorage` 不能用時退回「這次開著的頁面只播一次」（記在記憶體）。
- 階段若倒退（例如有人把已確認的比分改判退回），不重播、不收回；頁面依當下資料畫最終戰／一般模式。
- 手機觀賽頁：分頁在背景時不播，等回到前景才播。
- 直播疊加頁另有規則（見「直播疊加頁」）：只在輪詢時親眼看到階段往前切換才播；不看分頁在不在背景
  （PRISM 若把小工具當成背景頁，照套的話直播上永遠不會播，也不會有任何錯誤訊息）。
- `prefers-reduced-motion`：不震動、不閃光，動畫縮短。

## 手機觀賽頁（`tournament.html?t=`）

### 最終戰開場（全螢幕，約 4 秒）
- 固定在最上層的全螢幕圖層：變暗 → 翰林團體圖從右上、貿聯團體圖從左下衝進來（斜向對角）→「冠軍時刻」金色大字砸下（閃光、震動）→ 大字放大淡出 → 整個圖層淡出。
- 點一下可以略過。
- 翰林圖的人物在下緣被裁切，用漸層遮罩淡出（示範頁已驗證）。

### 最終戰模式（頁面內，一直到冠軍揭曉）
- 點數比分區（`#pointsSection`）換成主視覺：深色底、兩隊團體圖變暗當背景、兩側隊色光暈慢慢呼吸、中間大比分（總點數），上方「冠軍時刻」字樣，下方標出最後一輪的場次（例：`最終戰　第四點 混雙B · 第五點 男雙B`）。
- 原本點數比分板的每點明細、應援條仍在主視覺下方照常運作；直播框、賽程不受影響。
- 「總點數」這類小字壓在團體圖上，要加深色文字陰影才讀得到（示範頁 v13）。

### 冠軍揭曉（全螢幕，約 8 秒）
- 全螢幕圖層：勝方團體圖從它那一側衝進來、停在畫面下半部；上半部是勝方隊名色塊（隊色樣式）、金色「奪冠！」大字、
  最終總點數（勝方在前，例：3 : 2）；勝方隊色與金色的長方形紙花飄落（不是火焰）。
- 紙花在團體圖前面、文字後面，不能蓋住「奪冠！」與隊名（紙花疊在字上時，藍色紙片在金字上像破洞）。
- 點一下可以略過，約 8 秒後自動淡出。
- 淡出後頁面停在最終結果：應援數公布照舊；「比賽結束：○○ 以 3：2 勝出」這句放在主視覺的膠囊裡。
  主視覺出現期間（最終戰與揭曉後），點數比分板原本的大比分與「🏆」橫幅隱藏（字已經在主視覺裡，避免同一句出現兩次），每點明細照常；
  最終戰階段若冠軍已提前確定，主視覺比分下的小字由「總點數」改成「○○ 已拿下 3 點，確定勝出」，原本橫幅的資訊不消失。主視覺改成冠軍狀態：
  - 上方字樣改「🏆 冠軍」，大比分顯示最終總點數，下方膠囊改「比賽結束：○○ 以 3：2 勝出」。
  - **勝方團體圖固定在下半部（跟揭曉畫面同一個位置）、亮；敗方放上半部、變暗變灰**，比分永遠壓在暗掉的敗方上。
    原因：照原本位置放的話，翰林勝時亮起來的翰林圖在上半部，會蓋住比分，「總點數」看不清楚。
  - 光暈只留勝方隊色，從下方亮起。
  - 揭曉圖層淡出時，團體圖原地淡入（不再從側邊滑進來）；最終比分晚約 0.45 秒才浮上來，兩組大字不重疊。

## 直播疊加頁（`overlay.html?t=`）

- 最終戰開場：整個疊加頁播 VS 開場（兩隊一左一右面對面、大字砸下），約 4 秒後兩隊退出，回到透明畫面＋左下比分條；比分條多一個「冠軍時刻」金色標籤，第二行顯示最後一輪的場次。
- 冠軍揭曉：整個疊加頁播約 8 秒。勝方團體圖從它那一側衝進來、佔那一半（滿高）；隊名色塊＋「奪冠！」＋比分放在**另一半**、
  垂直置中，不壓在選手身上；金色光暈跟著字那一側。之後回到比分條（標籤改「🏆 冠軍」，第二行沿用現有「比賽結束：○○ 以 3：2 勝出」）。
- 疊加頁不能點（PRISM 網頁小工具），所以都是自動結束；動畫圖層一律由計時器在時間到時移除，不依賴 CSS 動畫的結束事件
  （小工具若被當成背景頁，動畫可能不跑、結束事件不來，圖層會一直蓋著直播）。
- **只在親眼看到階段切換時播**：疊加頁載入時先記下當下階段、不播；之後輪詢看到 `none → final` 才播開場，
  看到 `final → done`（或 `none → done`）才播揭曉。同時照樣記 `localStorage`，同一台裝置不重播。
  - 好處：PRISM 重新載入小工具（賽前作業本來就教「空白或改版就重新載入」）、或直播中途才加上疊加頁，都不會突然播一次全螢幕動畫蓋住正在打的球；
    不需要先確認 PRISM 會不會保留 `localStorage`。
  - 代價：小工具若在最後一輪前一刻才開、或剛好在切換那 10 秒內重載，就會錯過開場或揭曉，畫面直接是當下階段的比分條。
    友誼賽 18:15 開播時就會開著小工具，最終戰約 19:30，風險低。
- 直播用透明背景：開場與揭曉期間有自己的深色底（蓋住直播畫面幾秒是預期的），結束後恢復透明。
- 疊加頁讀取失敗時保留上一次畫面的規則不變；冠軍時刻出錯只寫主控台。

## 隊色：主客場代表色

| | fill（底色） | edge（邊） | ink（字） |
|---|---|---|---|
| 貿聯 | `#0077cb` | `#0077cb` | `#ffffff` |
| 翰林 | `#ffffff` | `#187fc4` | `#14649c`（文字用加深的藍，見下） |

- `teamColorById` 保留（回傳 fill），既有呼叫端逐一改成用 style：
  - 隊伍色點（點數比分板、賽程、排名表）：底色 fill＋2px edge 外框（翰林在白底輸分頁也看得到）。

  - 應援泡泡：底色 fill、字 ink、1px edge 外框（現在一律白字，翰林白底會看不見）。

## 測試

- `finalPhase`：非比點／不是貿聯翰林 → none；最後一輪前未全確認 → none；全確認 → final；全部確認 → done；finished → done；只有一輪 → 不進 final；最後一輪先確認、前面未確認 → none。
- `championInfo`：勝方、比分、左右邊。
- 只播一次：第一次回 true、之後 false；`localStorage` 丟例外時退回記憶體；第一次看到就是 done 時不播開場。
- 觀賽頁渲染（jsdom）：觀賽模式 final → 掛開場與主視覺；輸分模式 final → 都不掛；done → 掛揭曉；冠軍時刻出錯 → 賽程照樣 15 列、renderAll 不拋錯。
- 疊加頁（jsdom）：final → 開場後回比分條、多「冠軍時刻」標籤；done → 揭曉後回比分條；出錯不出現錯誤字。
  - 載入時就已經是 final／done → 不播，直接是對應的比分條；輪詢看到 none → final、final → done 才播。
  - 動畫圖層在時間到時一定被移除（假計時器推進，不觸發 animationend 也要移除）。
- 手機揭曉後的主視覺：勝方為翰林時，翰林團體圖在下半部、貿聯在上半部變暗（反過來也測）。
- 隊色：`teamStyleById` 貿聯翰林用代表色、第三屆 5 隊不變；色點有 edge 外框；泡泡字色用 ink；疊加頁色點；翰林小字對比 ≥ 4.5。
- 既有釘住紅／青的測試（`tournament-render`、`overlay`、`team-points`）改成代表色。
- 瀏覽器實看（本機假資料）：手機 375px 的開場／主視覺／揭曉、直播 16:9 的開場／揭曉、輸分頁白色主題的色點與應援條。
