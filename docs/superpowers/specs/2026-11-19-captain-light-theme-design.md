# 輸分頁改白色（2026-11-19）

## 意圖
孟娜 11-19 16:00 許願：輸入分數的頁面用白色，跟觀賽頁的外觀分開，怕大家搞混。使用者答應，16:05 拍板「所有比賽都套用」。
輸分頁與觀賽頁是同一個 `tournament.html`，差別只在網址：`?c=<隊長通行碼>` 是輸分連結、`?t=<觀賽通行碼>` 是觀賽連結。
兩種頁面現在長得一樣（F1 黑底），拿錯連結時看不出來。

## 目標
- 輸分連結（`?c=`）打開是白色版；觀賽連結（`?t=`）維持現在的黑色版。
- 一打開就是白色，不先黑一下再變白。
- 手機瀏覽器頂端那條（`<meta name="theme-color">`）在輸分頁也是白色。

## 非目標
- 不改觀賽頁、直播疊加頁（`overlay.html`）的外觀。
- 不改計分、比分驗證、應援、直播框的行為。
- 不加「這是輸分頁」之類的文字標示（沒被要求；若要再另議）。
- 不做逐場的開關（使用者拍板所有比賽都套用）。

## 反目標
- 已發出的 QR code（11-17 交付）失效 → 網址不能改。
- 觀賽頁的外觀有任何變化。
- 白底上看不清的字（綠色「已確認」、黃色「等待」、項目標籤的淡色字）。

## 限制
- 純前端、無建置步驟；`?v=` 與 `sw.js` 的 `CACHE_NAME` 一起換版（v20 → v21，測試會擋）。
- 已開過輸分頁的手機第一次打開仍是舊版，重新整理一兩次才換新版（SW 先給舊頁）。

## 做法（Approaches）
1. **同一頁、看網址換色（採用）**：頁面在 `<head>` 就依網址決定顏色，樣式檔加一組白色版的顏色。網址不變、不先黑一下。
2. 另開輸分專用頁面：已發出的 QR code 失效，不採用。
3. 另載一份白色樣式檔：要等 JS 判斷後才載入，畫面會先黑一下，不採用。
4. 只改友誼賽（依比點賽制或資料庫開關判斷）：使用者 16:05 改為所有比賽都套用，不採用。

## 已決定的部分
- 判斷規則沿用 `parseTokenFromUrl`：`mode === 'captain'` → 白色，其餘（觀賽、壞連結）→ 黑色。不另寫一份網址規則。
- 在 `<head>` 載入 `tournament-form.js` 與新的 `page-theme.js`，於 `<html>` 加上 `theme-light` class，並把 theme-color 改成 `#ffffff`；在 body 畫出來之前就生效。
- 樣式：`:root.theme-light` 重新定義 `--f1-*` 顏色變數；寫死深色的地方（輸分彈窗、輸入框、提示訊息、按下應援的回饋、項目標籤字色）在 `.theme-light` 底下加淺色版。觀賽頁原有規則一字不動。
- 維持：隊伍顏色紅 `#e10600`、青 `#00a19c`，頂端紅線，`--f1-red`。
